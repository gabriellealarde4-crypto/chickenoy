# Chickenoy

## Running the project (recommended)

1. **Open the workspace**
   - In VS Code, open **File → Open Workspace...** and select `friedchicken.code-workspace`.

2. **Run the backend server**
   - Open the **Run and Debug** panel (left sidebar). 
   - Select **Run Chickenoy Server** and click the green ▶️ button.

3. **Open the site in your browser**
   - Navigate to: `http://localhost:5000`

## Tasks (alternative)

From the Command Palette (`Ctrl+Shift+P`):
- Run Task → **Install Backend Dependencies**
- Run Task → **Start Backend Server**

## Notes
- If you don't see any Run/Debug configurations, make sure you opened the workspace file (`friedchicken.code-workspace`) instead of a single file.
- Do not press F5 while a JSON or HTML file is active — use the Run button in the panel instead.
