# Logo Setup Guide for Chickenoy

## File Location
Place your `logo.png` file in this directory: `Frontend/images/logo.png`

## Requirements
- **Filename**: `logo.png` (exactly as shown)
- **Format**: PNG with transparent background recommended
- **Recommended Size**: 
  - Width: 400-500px
  - Height: 150-200px (will scale to 50px in navbar)
  - Aspect Ratio: 2:1 or 3:1 (wider than tall)

## File Upload
1. Save your Chickenoy logo as `logo.png`
2. Place it directly in the `Frontend/images/` folder
3. The logo will automatically display in:
   - Navigation bar (top-left) on all pages
   - Perfectly aligned and sized

## Current Setup
✓ All HTML pages are configured to use `logo.png`
✓ CSS is optimized for logo display
✓ Fallback emoji (🍗 Chickenoy) will show if image is missing
✓ All animations and transitions are ready

## Testing
Once you add the logo.png file:
1. Refresh your browser (Ctrl+Shift+R)
2. Navigate through all pages
3. Logo should appear consistently in navbar
4. Logo has hover animation (scales up slightly)
